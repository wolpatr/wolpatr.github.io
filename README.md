# web-portfolio — `wolpatr.github.io`

The public portfolio site (MkDocs Material, user-site pages: `https://wolpatr.github.io`)
plus the local Grafana evidence dashboard (`dashboard/`), built from one
spec: `.scratch/portfolio-web/spec.md` in the data_agent working copy.

Everything public-facing is declared content or scraped public signals:
no credentials, no private data (the sanitizer gate refuses to build on it).

## Layout

| Path | Role |
|---|---|
| `content/progress.yaml` | The hand-maintained content file: site meta, live-arms tile, declared evidence (trials recorded, gate week), curated projects (slug/repo/status/percent/description), honest tail. |
| `content/visuals.json` | Build-time scraped signals (push dates, commit sparklines, languages), committed as the last-known-good scrape; regenerated by `web scrape` / `web build`. |
| `docs/now.md` | Hand-written dated "Now" entries, latest first (`## YYYY-MM-DD`). |
| `docs/index.md`, `docs/projects/*.md` | Generated at build time (gitignored) from the above. |
| `docs/stylesheets/portfolio.css` | Hand-written once: bars, chips, tiles. |
| `dashboard/` | Local Grafana OSS 13.0.2 compose + provisioned dashboards + news materializer. |
| `.github/workflows/deploy.yml` | Cron (daily 04:00 UTC) + push: scrape → generate → sanitize → mkdocs → Pages (SHA-pinned actions, no secrets). |

## Site tooling (uv)

```bash
uv sync                 # one-time install (mkdocs-material, pyyaml, pytest)
uv run web build        # scrape + generate + sanitize gate + mkdocs build → site/
uv run web build --no-scrape
uv run web scrape       # refresh content/visuals.json only
uv run web lint         # sanitizer contract gate over content/ + docs/
uv run web serve        # generate + mkdocs serve on 127.0.0.1:8000
uv run pytest           # test suite (5 seams from spec §7)
```

Editing content: change `content/progress.yaml` (validated: strict keys, kebab-case
unique slugs, percent 0-100) or add dated entries to `docs/now.md`, then
`uv run web build`. A project addition also needs its nav line in `mkdocs.yml`.

## Publish (one-time human setup, spec §8)

1. Create the GitHub repo `wolpatr.github.io`, `git remote add origin <url>`, push `main`.
2. Settings → Pages → Build and deployment → **Source: GitHub Actions**.
3. HTTPS is automatic on `wolpatr.github.io`.

The declared percentages/statuses are hand-held: update them whenever the truth
changes, and let the scraped layer carry the rest.
